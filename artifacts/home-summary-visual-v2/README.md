# Web 摘要卡第二轮动态验收

2026-10-22，真实 Web 浏览器 + HTTP fixture。运行 `node artifacts/home-summary-visual-v2/check.mjs`；服务地址 `http://127.0.0.1:5666`。测试只操作真实控件，未注入 Vue 状态，未访问真实账号业务数据。

已通过 390 / 820 / 1440 px × 深浅主题共六组合：

- 六卡展示与长标题；设备图片和视频封面各覆盖成功、失败、无图；图片响应前后缩略图尺寸、卡片高度与后续位置相同，无横向溢出。
- 收支概览 / 收入 / 支出各自范围独立；点击本年后延迟响应，成功前保留本月选中、标签与金额；待处理范围按钮 aria-busy=true；成功后三者共同切换。
- 收入查询本年失败后仍保留本月标签、选中和金额；随后选择全部恢复。
- 支出从本年慢请求快速切换全部，全部先返回后仍保持全部，晚到的本年响应未覆盖。
- 混合范围最终保持收支概览=本年、收入=全部、支出=全部。
- 收入卡新增直接打开真实收入表单；填写 123.45、选择类别并 POST /income，收入全部显示 100,123.45，收支概览本年对应刷新。
- 支出卡新增直接打开真实支出表单；填写 88.50，记账金额自动联动，选择类别和支付方式并 POST /expense，支出全部显示 20,088.50，收支概览本年对应刷新。
- 所有 ID 使用超过 JS 安全整数的大整数 string；浏览器 pageerror=[]。

媒体首屏布局补验（调整后的最终实现）：`media-layout-six-combinations.json` 保存六组合“API 返回前骨架 → 三条含长标题媒体数据”的测量，手机/平板均 250 → 250 px、桌面 280 → 280 px；每行 64 px，平板第三行完整可见。骨架包含与展示态对应的图片占位。API 数据到达与随后图片二进制到达分开测量，两段均通过。原 `results.json` 中首次骨架与数据高度可能不同，只能用于范围交互及图片到达阶段，不应据此声称旧版首次骨架等高。

`media-initial-results.json` 是延迟挂载财务表单后的定向复验：首屏零字典请求；收入首次点击打开表单且只查询 `income_type`，取消后支出首次点击打开表单且只新增 `exp_type` / `pay_type`，pageerror=[]。最终布局截图为 `*-media-initial.png` / `*-media-loaded.png`；运行 `node artifacts/home-summary-visual-v2/media-check.mjs` 可复现，`FAST=1` 仅定向复验桌面深色与首次点击。

`results.json` 保存六组合几何、请求参数/响应及写入记录。`*-month-images.png` 为各主题视口默认范围及图片状态；`*-independent-ranges.png` 为不同范围；`income-entry.png` / `expense-entry.png` 为真实表单；`updated-totals.png` 为提交后的指标。

首次四卡的空态、单条、加载、失败重试、笔记编辑和首页设置验证保留于相邻 `home-summary-visual/` 目录。移动端全页截图可能把应用固定顶栏拼接到中间位置；这是 Chromium 全页捕获滚动页面的产物，默认范围首屏截图可用于审查布局。

边界：本报告证明 Web 客户端与模拟响应的浏览器集成，不证明真实后端、线上数据、部署、移动端或图片存储服务。
